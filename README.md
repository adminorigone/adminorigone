# Origo One — Marketing Site

AI consultancy site for **Origo One**.  
Origo (Latin): origin, source, first cause. One: singular focus.

Positioning: redesign operations with AI before competitors do.

## Stack

- Next.js 14 · React · TypeScript
- Tailwind CSS · Framer Motion · Lenis · Three.js
- Fonts: Syne (display) · IBM Plex Sans · IBM Plex Mono

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Cinematic narrative homepage |
| `/services` | Transformations (outcomes) |
| `/process` | Approach & engagement models |
| `/work` | Case stories index |
| `/work/hirecar-marketplace` | Documentary case study |
| `/about` | Philosophy & team |
| `/discovery` | Strategy session CTA |
| `/contact` | Direct contact |

## Brand

All messaging lives in `constants/site.ts`.  
Wordmark: `components/BrandMark.tsx` — **Origo** in ink, **One** in signal.
